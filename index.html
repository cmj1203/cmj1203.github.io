만든 것

게임

  • 던전 서바이버자세히 몰려오는 몬스터 사이에서 살아남는 뱀서라이크 웹 게임이에요. 컴퓨터와 휴대폰에서 할 수 있어요!
  • Desktop Uparupa자세히 바탕화면 물속에 사는 우파루파를 키우는 macOS · Windows 앱이에요. 먹이를 주고, 같이 놀고, 꾸밀 수 있어요!
  • 라이브캔버스자세히 키 하나로 박자를 맞추면 크레파스 한붓그리기가 완성되는 웹 리듬게임이에요.

앱·도구

  • AI 계정 사용량 메뉴바자세히 Claude Code와 Codex 계정마다 사용량이 얼마나 남았는지 메뉴바에서 바로 볼 수 있는 macOS 앱이에요.
  • GitHub 레포 개요자세히 GitHub 저장소의 README와 폴더 구조를 읽고, 어떤 프로젝트인지 한국어로 쉽게 알려 주는 Chrome 확장이에요.
  • 오메추자세히 오늘 뭐 먹을지 메뉴를 골라 주고, 그 메뉴를 파는 주변 식당까지 찾아 주는 웹사이트예요.
  • photo2caricature자세히 인물 사진을 넣고 스타일을 고르면 캐리커처로 그려 주는 도구예요. 다 그린 그림도 말로 더 고칠 수 있어요!
  • img3d자세히 사진 한 장을 올리면 빙글빙글 돌려 볼 수 있는 3D 모델로 만들어 주는 도구예요. 인물·물건도, 방 같은 공간도 돼요!
  • omo 디스코드 봇자세히 휴대폰 디스코드에서 컴퓨터의 AI 코딩 세션을 보고 일을 시킬 수 있는 봇이에요. 세션마다 스레드로 나뉘어요!
